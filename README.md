**ES** — Descomprime esta carpeta al lado de `Pokefus UpLauncher` y abre
`Pokefus en espanol.bat`. No hay que instalar nada: usa el propio juego como
intérprete. Para quitarla, `quitar traduccion.bat` deja el cliente byte a byte
como estaba.

**FR** — Décompresse ce dossier à côté de `Pokefus UpLauncher` et ouvre
`Pokefus en espanol.bat`. Rien à installer : le jeu lui-même sert
d'interpréteur. Pour l'enlever, `quitar traduccion.bat` remet le client octet
pour octet comme il était.
